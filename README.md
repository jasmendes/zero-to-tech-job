# zero-to-tech-job
# Workshop: Do Zero ao Primeiro Emprego Tech

Este workshop é composto por **4 módulos principais**, totalmente práticos e focados em preparar novos talentos para o primeiro emprego na área de tecnologia.

---

# 📘 Módulo 1 — Terminal, Chocolatey, Python e Jenkins

## 🎯 Objetivo
Ensinar o uso básico do terminal (PowerShell) e instalar ferramentas essenciais para automação e desenvolvimento.

## Conteúdos
- Introdução ao PowerShell
- Comandos básicos: navegar, criar pastas, criar arquivos
- Criar primeiro script PowerShell
- Instalar **Chocolatey**
- Instalar **Python 3** via Chocolatey
- Instalar **Jenkins** via Chocolatey
- Criar o **primeiro job no Jenkins**

## Resultados deste módulo
Ao final deste módulo o aluno saberá:
- Usar o terminal com segurança
- Instalar aplicações via gerenciador de pacotes
- Criar e executar scripts simples
- Criar e rodar jobs no Jenkins

➡️ Conteúdo completo no documento **Exercícios Iniciais**

# 📗 Módulo 2 — GitHub + Deploy Automático com Jenkins

## 🎯 Objetivo
Criar uma conta GitHub, publicar um website e configurar o Jenkins para enviar atualizações automaticamente.

## Conteúdos
- Criar conta GitHub
- Criar repositório
- Criar página HTML simples (`index.html`)
- Fazer o primeiro commit e push
- Ativar **GitHub Pages**
- Criar job no Jenkins para atualizar o site automaticamente

## Resultados deste módulo
Ao final deste módulo o aluno saberá:
- Trabalhar com Git e GitHub
- Publicar websites no GitHub Pages
- Integrar Jenkins com GitHub
- Automatizar deploys

➡️ Conteúdo completo no documento **Exercício GitHub + Jenkins**

# 📘 Módulo 3 — Projeto Realista (Parte 1)
## **Git Edit → Git Trigger → Build no Jenkins**

### 🎯 Objetivo
Simular um fluxo de trabalho mais próximo do mercado usando Git + Jenkins, incluindo edição de código, commit, push e automação de build.

### Conteúdos
- Editar código localmente
- Uso correto de branches (main, feature)
- Criar commits significativos
- Git push para GitHub
- Configurar webhook GitHub → Jenkins
- Jenkins receber o trigger automaticamente
- Executar build e logs

### Resultado
O aluno aprenderá:
- Como equipes reais colaboram usando Git
- Como Jenkins detecta mudanças automaticamente
- Como configurar pipelines simples

# 📗 Módulo 4 — Projeto Realista (Parte 2)
## **Deploy Automático + Notificação no Slack**

### 🎯 Objetivo
Completar o pipeline iniciada no Módulo 3 com deploy final e notificações profissionais.

### Conteúdos
- Jenkins: pós-build de deploy automático (copiar arquivos ou atualizar site)
- Deploy para GitHub Pages ou pasta web local
- Criar Webhook do Slack
- Enviar mensagem automática ao Slack com status:
  - 🟢 Sucesso
  - 🔴 Falha

Exemplo de mensagem enviada:
```
Deploy realizado com sucesso!
Branch: main
Hora: 14:32
```

### Resultado
O aluno terá um pipeline completo:
1. Edita código
2. Faz commit e push
3. GitHub envia trigger ao Jenkins
4. Jenkins faz build
5. Jenkins faz deploy
6. Slack recebe notificação

---

É um fluxo real usado em empresas, perfeito para colocar no portfólio.

# 🚀 Objetivo Final do Workshop
No final dos 4 módulos, o aluno terá:
- Experiência real com terminal
- Instalação e uso de ferramentas profissionais
- Noção prática de automação
- Deploy contínuo simples (CI/CD básico)
- Um site publicado e atualizado automaticamente

Este é o primeiro passo para o primeiro emprego tech.
